# 에이원 팜플렛 (배포용)

에이원코리아 보험료 안내 팜플렛 5종을 웹에서 바로 보고 인쇄하는 페이지입니다.

- `index.html` — 잠금 화면 + 팜플렛 (파일 하나로 완결)
- `icon.png` — 잠금 화면 아이콘

## 쓰는 법
1. 회사 비밀번호를 넣고 **열기**.
2. 위쪽에서 팜플렛을 고르고 담당자를 선택.
3. **🖨️ 인쇄 / PDF** — 용지 **A4**, 여백 **없음**, 배율 **100%**.
   인쇄물에는 잠금 화면과 위쪽 막대가 나오지 않고 팜플렛만 나옵니다.

## 수정
이 페이지는 `projects/2026_onepage/`(에이원 팜플렛 편집기)에서 만들어집니다.
편집기 원본을 고친 뒤 `python3 make_pamphlet_web.py` 로 다시 만들고 이 저장소에 올리면 됩니다.
